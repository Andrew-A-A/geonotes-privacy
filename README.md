# geonotes-privacy

Hosts the privacy policy for **GeoNotes** (`com.deadjoy.geofencednotes`), the Android
location-reminder app, at <https://andrew-a-a.github.io/geonotes-privacy/> — the URL entered in
Play Console under *Policy → App content → Privacy policy* and linked from the app's Settings.

`index.md` is the policy. Edit it, bump "Last updated", push; GitHub Pages republishes it.
